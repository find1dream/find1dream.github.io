# find1dream.github.io

Personal site of Linfeng Chen, in English, Japanese and Chinese. Built with Astro, deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `master`.

- Content (site and résumé): `src/data/content.ts`
- Pages: `/en/`, `/ja/`, `/zh/`; printable résumé at `/<lang>/cv/`
- Résumé PDFs: `public/cv/`, regenerated by `make cv` and committed
- Activity heatmap: `src/data/contrib.json` (dates and commit counts only), regenerated by `scripts/contrib.sh` from the local work repos

```sh
make install   # npm install (in a node container)
make dev       # http://localhost:4321
make cv        # rebuild the three PDFs
```
